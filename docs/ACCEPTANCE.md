# 验收

在仓库根目录运行 `python -m pytest -q`。CPU 测试读取随仓库提供的真实分词器和冻结地图。采集测试使用可控制输出的采样器，使边界、种子、预算、执行后的棋盘与 WebShop 已选规格可以逐项核对。

| 检查 | 证据 |
| --- | --- |
| 三种目标 | 在 M 为 1、2、4 时穷举小型分布，检查逐轨迹长度分母、组统计、共享前缀和 PG / KL 的删行行为 |
| 原始轨迹与重掷 | 覆盖留一题校准、抽签落盘顺序、前缀逐位一致、重掷当回合终局和无动作判据 |
| 入口与基线 | 各 UCF 别名的 mock smoke 经过采集和权重入口。基线检查与 `v3-final` 对同一合成输入的权重行逐位比较 |
| 队列和产物 | 用子进程替身检验跳过、恢复、重试和失败后继续。验证曲线、最终测试和分叉成本从轻量文件汇总 |
| FrozenLake | 低分与高分的 CPU 模拟均沿启动时选定的地图走完 400 步、每 25 步固定验证、最后测试 |

目标训练机上，先运行 README 的 `--check` 校验数据与模型，然后用真实 `--smoke` 检查显存、vLLM 采样、优化、权重同步和验证。WebShop 的商品索引还需通过 `scripts/check_webshop_live.py` 现场核验。[安装](INSTALL.md) · [WebShop](WEBSHOP.md)
